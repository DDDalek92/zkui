# D01-C：仅追加审计差量的旧驱动副本恢复预演

2026-10-15；独立检出自最新远程 master `498fe7f1d540300b7cd3cef0091113cb9cfe73b7`（#34合并后）。这是测试自建数据的有限离线预演，不是生产迁移/降级工具，也不改变运行时依赖。

## 复核的问题与限定策略

既有rollback只恢复切换前封存快照，丢失候选库后来新增的记录，不能称无损回退。本增量限定“冻结写入后，原历史逐字段不变，只新增大于基线最大ID的审计行”；不是任意表同步/更新删除回迁。

`H2AuditDeltaProbe`只由原隔离驱动测试入口调用，每个进程仍核对随机所有权标记、单一H2驱动和实际版本。基线由旧1.3.174/Flyway2原V1建立；新2.5.252仅使用独立LEGACY候选路径，旧驱动只打开封存库的另一个复制品，不读取新格式文件。

## 有限夹具及验收

- 原三条历史包含NULL/空串、中文emoji、日期、500字符、非连续大于2^53的ID；候选库另新增两条，包含NULL日期/文本、空IP、固定毫秒日期、中文emoji、HTML、空白/换行/引号/反斜杠。
- 导出前逐字段核对所有基线ID行及原迁移表全字段不变；修改或删除原记录均拒绝，并且拒绝发生在生成差量文件前。新行按ID有序导出；本夹具为两行，硬预算1000行/1MiB载荷，绑定随机所有权和原快照SHA256。
- 载荷为**测试专用**带版本的Java DataInput/DataOutput格式，文本明确使用modified-UTF并单独标记NULL（不与空串混同），日期用Instant秒/纳秒。不承诺公共交换格式或任意时间精度。保存独立载荷SHA256以检测本地意外变动，不是签名/身份认证。
- 消费方先核对载荷大小/hash/版本/所有权/原快照绑定及行ID顺序/字段边界，再创建旧恢复副本。载荷单字节被改动时，必须在创建/打开恢复副本前拒绝。
- 在旧副本上先验证原快照，再在一个JDBC事务中按精确ID参数化插入。已有同ID且所有字段完全相同才允许跳过；任何内容冲突拒绝整批。提交前比较完整候选历史快照及原迁移记录；不复制/删除/repair Flyway记录。
- 正常路径连续回放两次，逐字段结果不变，再验证旧引擎新增记录的生成ID大于恢复后最大ID，关闭重开后完整六条历史/迁移记录保留。另一个负向副本预置第二个差量ID的冲突内容，确认第一行曾进入本批事务但最终全部回滚，既有冲突行不被覆盖。这里只保证行事务回滚，不宣称数据库序列分配本身可回滚。
- 原始导出字节、封存全文件名/SHA256保持不变；正常恢复也核对候选文件全清单/SHA256不变。只写测试新建的旧恢复副本，绝不将新格式库交给旧引擎。
