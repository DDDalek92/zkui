## 当前验收阶段

1. 将运行 SBOM、二进制哈希、OSV 查询及第三方法律文件库存纳入每次 PR CI。该自动查询不覆盖所有供应链，也不代替许可证分发审核。
2. 补齐许可证/版权通知；另审前端/构建/测试/容器依赖；修复默认凭据和代理信任剩余边界。
3. 历史库增加真实文件系统权限/磁盘空间失败、非 UTC/时间精度、更多方言及恢复矩阵；所有操作限独立合成副本。
4. 真实 LDAPS/AD、生产IPv6网络、反向代理 HTTPS；当前Chrome/Firefox真实流程已由#46验证，IPv4/IPv6回环验收接续中；无法获得原 Windows 9s:1s 环境时保留阻塞，不能把普通 Windows CI 称为原性能故障修复。
5. 增强需求：逐节点 ACL 编辑、左栏属性、新导入协议、Kerberos；可选 hosts 初始化已完成且默认关闭。每项独立设计安全边界和验收。

## 正式发行门槛

- 核心功能、安全回归及准确 head 全 CI 通过；所有关键风险和外部环境缺口有明确结论。
- 历史库备份、迁移、失败恢复和审计差量有明确支持范围，禁止操作唯一旧库或清除迁移证据。
- SBOM、依赖查询、许可证通知、部署文档和可复现构建齐备；清楚区分已验收组合与未知组合。
- 发布说明、兼容性/已知限制完成；正式 Release 和公共镜像尚未发布。
